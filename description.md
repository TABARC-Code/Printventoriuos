# Description

PrintVentorious is a fork of Printventory: an Electron desktop app (with an optional LAN web server mode and an MCP server) for keeping a 3D-print model library in order. It scans folders and ZIPs for STL, 3MF and similar files, makes thumbnails, and lets you tag, rate, track print history, spot duplicates, and send things to your slicer.

This fork adds a unit-test runner with CI, a fix for slicer detection with Windows-style paths, keyboard focus and reduced-motion CSS, and a written improvement plan. See `IMPROVEMENTS.md` for what's done, what's next, and what I couldn't verify.
